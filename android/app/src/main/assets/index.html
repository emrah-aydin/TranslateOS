TranslateOS

LG TV'ne telefondan kurulum

Başlamadan önce

  • TV'de Developer Mode uygulamasında Dev Mode Status ve Key Server açık (ON) olmalı.
  • Telefon ve TV aynı Wi-Fi ağında olmalı.

1TV'ni seç

TV aranıyor…

2TV'deki kodu yaz

Developer Mode uygulamasında Passphrase olarak yazan 6 karakter.

    Kurulum tamam 🎉

    TranslateOS TV'nde açıldı. PS5'te altyazılı bir oyun aç; Türkçe sarı yazıyla gelir.

    İlk açılışta TV izin isterse İzin ver'e bas. Menü için kumandadan OK.

    Bu uygulamayı artık kapatabilirsin. Güncellemek için yeniden açıp Kur'a basman yeterli.
